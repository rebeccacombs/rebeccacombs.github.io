### <span style="color:rgb(255, 223, 128)">Implement an algorithm to determine if a string has all unique characters. What if you cannot use additional data structures?</span>

- With data structures this is fairly easy to think about
- Something you could do is sort the string by its characters and in-place check if string[i] == string[i+1]
	- If true return false (string isn't all unique characters)
	- Pros of this are that it is way less memory intensive since you aren't using any data structures 
<br />


Let's look at a java implementation of this solution step by step: 
- First we gotta convert the string to a character array
- We can use this or .toCharArray() method (might need to be imported)
```java
char[] ch = new char[s.length()]; 
for(int i = 0; i < s.length(); i++){
	ch[i] = s.charAt(i); 
}
```

<br />

- Next we sort the char array :) 
- I ought to practice [[merge sort]] since that is one of the *best* worst-case runtime sorting algorithms, and is what would be used to sort a character array. 
```java 
Arrays.sort(ch); //;p 
```

- Finally, loop through sorted character array and keep track, only returning false if we reach the condition of the if statement 
	- checks if two adjacent chars are the same
```java
for(int i = 0; i < ch.length-1; i++){
	if(ch[i] == ch[i+1]){ 
		return false; 
	}
}
return true; 
```

\
Now all together with a main method, the <span style="color:rgb(168, 225, 107)">solution with an array data structure:</span>
```java 
import java.util.Arrays;

public class isUnique{
	public static boolean unique(String s){
		//first we gotta convert the string to a character array
		char[] ch = new char[s.length()]; 
		for(int i = 0; i < s.length(); i++){
			ch[i] = s.charAt(i); 
		} // can use this or .toCharArray() method (might need to be imported)

		//sort the char array 
		Arrays.sort(ch); //;p 

		//loop through sorted character array and keep track 
		for(int i = 0; i < ch.length-1; i++){
			if(ch[i] == ch[i+1]){ //checks if two adjacent chars are the same
				return false; 
			}
		}
		return true; 
	}
	
	public static void main(String[] args){
		String test1 = "abcdefg"; 
		String test2 = "afbcdfh"; 

		System.out.println(unique(test1)); 
		System.out.println(unique(test2)); 
	}
}
```

If copypasted into vscode can be ran with `javac isUnique.java` followed by `java isUnique` :) 

</br> 

- Without additional data structures it is quite memory intensive. 
	- A nested for-loop could be used. 
	- <span style="color:rgb(168, 225, 107)">Solution w/o data structures: </span> 
```java
for(int i = 0; i < str.length() -1; i++){
	for(int j = 1; j < str.length(); j++){
		if(str[i] == str[j]){
			return false; 
		}
	}
}
return true; 
```

Here, it is important to note the time vs memory tradeoff of using a nested for loop for an in-place check, which is O(n^2). 

- The first solution is using a char array, which while requires memory for each character in the string, only runs in O(n) time.

#### Practicing in python 
With data structures: 
```python
def main(): 
	s = "abqcdefg"  
	print(unique(s)) 

def unique(s):
    srted = ''.join(sorted(s))

    for i in range(len(s)-1):
        j = i+1
        if(srted[i] == srted[j]): 
            return False; 
    return True

main() 
```

Without data structures: 
```python
def main(): 
	s = "abqacdefg"  
	print(unique(s)) 

def unique(s):
	for i in range(len(s)): 
		for j in range(i+1, len(s)):  
			if(s[i] == s[j]):
				return False
	return True;

main() 
```
